# Benchmarking v2

This benchmark measures session processing from start to finish using real sessions. A reviewed session is captured into a benchmarks folder. A run then re-runs the automatic steps in isolation and scores the resulting role transcript against the reviewed one. It reports text accuracy, role accuracy (correct / unassigned / wrong) and a glossary-term score, and keeps a history of runs.
