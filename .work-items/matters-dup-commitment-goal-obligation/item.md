# Matters Duplication: Commitments Restated as Goals or Obligations

A Development records an agreement, promise or accepted job, and a Goal or Obligation restates the same commitment. Seen in all four analysed Brandonsford Sessions. The goal is a Session Summary in which this repetition no longer occurs, while distinct information is preserved.

This is pattern P1 from the [duplication analysis](../reduce-session-matters-duplication/analysis.md) of the parent item [Reduce duplication across Matters within a Session](../reduce-session-matters-duplication/). See [Intent](intent.md) for the pattern shape, the Matters categories it shows up in, the observed occurrences, and the quality rubric.

Closed 2026-10-29 at the user's direction, without implementation. This work is superseded by [Unified Matters Pipeline](../unified-matters-pipeline/), which replaces category-by-category Matters generation with a thread-based pipeline designed to prevent this duplication. No handling was decided for this pattern; its evidence remains reference material for the new item.
