# Table Recap: phrase in second person

The Table Recap is read aloud by the Game Master to the players, so it should address the party as "you" ("You caught the Clurichen"), while referring to individual player characters by name ("Dr. Uriah must give penance…") and to other characters and groups in the third person.

Context: the Matters prompts briefly wrote second person for the Session Summary, but the user reverted that, so Matters, Post-Session Matters and the Session Summary refer to "the party" (see [Improve Phrasing](../summary-improve-phrasing/progress.md)). The recap must therefore produce second person itself rather than inherit it. Keep in mind that changing Matters wording invalidates every Matters category and the following Sessions' Scene Logs, which is one reason the user kept that text in third person.

At capture, Table Recap generation was paused pending its replacement design. The replacement is now implemented under the [Spoken Table Recap contract](../table-recap-read-aloud-split/specification.md).

Closed 2026-10-28 at the user’s explicit request. Second-person conversion was implemented and verified as part of [Table Recap: spoken presentation from Session Summary](../table-recap-read-aloud-split/item.md); see its [completion record](../table-recap-read-aloud-split/progress.md).
