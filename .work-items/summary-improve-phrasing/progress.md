- **Headings:** `session_pipeline/session_summary.j2` keeps the settled headings in a `headings` mapping and loops over sections. Its comment says each Matters prompt names the heading it writes for.
- **Summary module:** `session_summary.py` keeps the `prepare`/`render` split and is model-free again. `persist` archives any leftover `summary.phrasing.json` under `legacy/narrative/`, as it does other legacy summary files, then deletes it. The file stays a Summary companion, so Clean Session also removes it.
- **Prompts:** each of the ten `generate_matter_*/system.md` prompts has a "Read-aloud wording" section for the field the Summary shows, naming its heading and an example:
  - Developments `title` → "Last session..."
  - Revelations `text` → "You learned"
  - New Assets `name` → "You gained"
  - Goals → "Your goals"
  - Goal Impediments → "Standing in your way"

- **Conflicts resolved:**

  - A few title examples in Goal Impediments and Opportunities now use "you".
- **Removed:** `phrase_session_summary` prompt, `summary_phrasing.py`, `PromptName.PHRASE_SESSION_SUMMARY`, the `summary_phrasing_effort` setting, the Summary's prior-Session, prompt, party and model dependencies, the CLI credential check, and Summary's membership in `MODEL_GENERATED_ARTIFACTS`.

  - The [Deterministic Session Summary specification](../deterministic-table-recap/specification.md) amendment was rewritten to match.
