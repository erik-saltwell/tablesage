# Matters Duplication: Revelations Restated as Goal Impediments

A Revelation records a fact learned this Session, and a same-Session Goal Impediment restates it as an obstacle. Seen in two analysed Sessions. The goal is a Session Summary in which this repetition no longer occurs, while distinct information is preserved.

This is pattern P3 from the [duplication analysis](../reduce-session-matters-duplication/analysis.md) of the parent item [Reduce duplication across Matters within a Session](../reduce-session-matters-duplication/). See [Intent](intent.md) for the pattern shape, the Matters categories it shows up in, the observed occurrences, and the quality rubric.

Closed 2026-10-29 at the user's direction, without implementation. This work is superseded by [Unified Matters Pipeline](../unified-matters-pipeline/), which replaces category-by-category Matters generation with a thread-based pipeline designed to prevent this duplication. No handling was decided for this pattern; its evidence remains reference material for the new item.
