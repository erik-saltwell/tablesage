# Make automatic steps more visually distinct in Session Processing

Automatic processing remains visible as part of the Session's history, but has
less visual emphasis than manual review points. Manual rows use a bold label;
automatic rows stay indented and muted, except when running or failed. Up and
Down move through manual rows only, while mouse selection still permits viewing
or restarting an automatic row.

No numerical rubric has been defined for this registered work item. The user
explicitly approved implementation.

Implementation and verification are recorded in [progress.md](progress.md).
