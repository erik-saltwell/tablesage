# Table Recap: one consistent voice

Use one grammatical person throughout. Headings address the players ("Your goals remain", "You learned", "Standing in your way") while bullets use third person ("The Party Caught…", "Trout's party must…", "Dr. Uriah must…"). The mixed voice makes paraphrasing aloud awkward.

Recommendation (not yet agreed): second person, since the GM is speaking to the players; individual character names stay where an item concerns one character.

Evidence: [001](../../deployment/campaigns/Brandonsford/001/table_recap.md), [002](../../deployment/campaigns/Brandonsford/002/table_recap.md), [003](../../deployment/campaigns/Brandonsford/003/table_recap.md), [004](../../deployment/campaigns/Brandonsford/004/table_recap.md). Item text comes from the Matters prompts, and headings from the recap renderer.

Table Recap generation is currently paused until its replacement is designed (see the [Deterministic Session Summary specification](../deterministic-table-recap/specification.md)); apply this to that replacement design rather than to the old model-generated recap.

Origin: GM-perspective review of the Brandonsford Session 001–004 outputs on 2026-10-28, treating them as material a GM uses at the table. The user prefers short, paraphrasable bullet lists over read-aloud box text.
