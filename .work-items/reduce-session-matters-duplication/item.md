# Reduce Duplication across Matters within a Session

Identify specific recurring patterns in which the same development is repeated across Matters categories without adding information. Develop precise rules for each pattern and an LLM pass during Post-Session Matters creation that improves the summary while preserving useful information.

See [Intent](intent.md) for the agreed goal, constraints, quality rubric (approved 2026-10-29), and unresolved details. This is a fresh effort; the previous deduplication design and plan are not adopted.

The [duplication analysis](analysis.md) of Brandonsford Sessions 001–004 (2026-10-29) identified six patterns. Each has its own work item, with this item as the parent that holds the analysis and the shared rubric:

- [Matters duplication: commitments restated as Goals or Obligations](../matters-dup-commitment-goal-obligation/) (P1)
- [Matters duplication: offers and plans restated as Opportunities](../matters-dup-offer-opportunity/) (P2)
- [Matters duplication: Revelations restated as Goal Impediments](../matters-dup-revelation-impediment/) (P3)
- [Matters duplication: one threat across threat categories](../matters-dup-threat-categories/) (P4)
- [Matters duplication: deal gains restated as New Assets](../matters-dup-deal-gain-new-asset/) (P5)
- [Matters duplication: open bargains restated across categories](../matters-dup-open-bargain/) (P6), which overlaps P1, P2 and P5

Closed 2026-10-29 at the user's direction, together with P1 to P6, without implementation. This work is superseded by [Unified Matters Pipeline](../unified-matters-pipeline/), which carries forward this item's approved rubric and uses the duplication analysis as its evidence. No pattern rules were decided and no LLM deduplication pass was built.
