# Table Recap: rephrase headings for listenability

Rephrase the Table Recap's section lead-ins so that, said aloud, they work as natural spoken transitions. Current lead-ins: "Last time:", "You learned:", "New resources:", "Your goals remain:", "Standing in your way:", "There are openings:", "Questions remain:", "Your commitments:", "Meanwhile:", "As we return:", "Next:". "New resources" and "There are openings" sound especially stilted aloud.

Also rephrase each section's child bullets so they read naturally right after their heading. A GM reads the heading and then each bullet as one spoken unit, so a bullet should continue the heading rather than repeat it or clash with it. For example, under "You learned" a bullet starting "You learned that…" sounds odd aloud; it should start directly with what was learned. The same applies to whatever headings are adopted: bullet phrasing and heading phrasing have to be designed together. Bullet text comes from the Matters prompts, so this probably means each prompt needs to know the heading its output appears under.

Keep consistent with the one-voice decision in [table-recap-consistent-voice](../table-recap-consistent-voice/), the read-aloud/GM split in [table-recap-read-aloud-split](../table-recap-read-aloud-split/), and the matching Session Summary item, [Improve Phrasing](../summary-improve-phrasing/).

Table Recap generation is currently paused until its replacement is designed (see the [Deterministic Session Summary specification](../deterministic-table-recap/specification.md)); apply this to that replacement design rather than to the old model-generated recap.
