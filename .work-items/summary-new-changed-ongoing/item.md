# Session Summary: distinguish new, changed and ongoing items

Stop repeating unchanged carried-forward items every Session at full length. Mark each item new, changed, or ongoing; give new and changed items a full bullet and collapse ongoing items to a terse line (for example "Still open: dragon's origin, missing shipments, the fairies").

Examples from [001](../../deployment/campaigns/Brandonsford/001/summary.md), [002](../../deployment/campaigns/Brandonsford/002/summary.md), [003](../../deployment/campaigns/Brandonsford/003/summary.md), [004](../../deployment/campaigns/Brandonsford/004/summary.md): "Farmer Gill's three sons are already hunting the dragon…", "Where did the new dragon near Brandonsford come from…" and "Why have shipments stopped reaching Brandonsford?" repeat word for word across all four Sessions.

Open questions: whether new/changed/ongoing status should be computed deterministically by comparing with the previous Session's Post-Session Matters or recorded upstream; how matching handles reworded items. See the [Post-Session Matters specification](../post-session-matters/specification.md).

Origin: GM-perspective review of the Brandonsford Session 001–004 outputs on 2026-10-28, treating them as material a GM uses at the table. The user prefers short, paraphrasable bullet lists over read-aloud box text.
