# Matters: clearer wording for Summary and Table Recap

Improve the upstream Matters wording used by the deterministic Session Summary so each bullet is easier to understand on first reading and easier to say aloud, without losing any fact, condition, amount, attribution, or uncertainty. Both the Summary and the Table Recap benefit. Applies to historical, present, and Open Matters.

The [saved intent](intent.md) records four settled wording rules (actor and action early, familiar verbs, break up crowded sentences, qualifications beside the claim), the rule to leave clear and carried-forward entries unchanged, worked examples, conflicts found in the current prompts, and the approved [quality rubric](intent.md#quality-rubric-approved-2026-10-28). The implementation [plan](plan.md) records the completed prompt and contract changes.

This is follow-up work to [Improve Phrasing](../summary-improve-phrasing/item.md), whose existing sentence-case and heading-fit guidance remains applicable. It was separated from the [Table Recap workshop](../table-recap-read-aloud-split/item.md) because general language clarity belongs upstream.

Completed at the user's explicit direction on 2026-10-28. Phases 0–4 are implemented in commit `f7a7352`; prompt wording and the contract amendment are complete. The planned Brandonsford regeneration and rubric evaluation were not performed, so output quality remains unassessed. See [progress.md](progress.md) for verification and publication status.
