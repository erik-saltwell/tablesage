# Enhance README

Help game masters arriving at the TableSage repository recognize the problems it solves, understand the benefits for their campaigns, and get started. Show a representative generated summary to make the payoff tangible.

## Quality rubric

Approved qualitative rubric for judging the enhanced README. Assess each dimension independently in words, with supporting reasoning.

| Dimension | What it values |
|---|---|
| Compelling benefit | Game masters recognize their own problems and quickly understand why TableSage would make their campaign life better. |
| Ease of adoption | Interested readers can understand what they need and confidently take the first steps toward a useful result. |
| Credible payoff | A representative generated summary makes the promised value tangible and sets believable expectations for the output. |

Priority order: compelling benefit first, ease of adoption second, credible payoff third. This order guides tradeoffs; it does not assign numerical weights or combine the dimensions into an aggregate judgment.

The dimensions are distinct: a README can be compelling but difficult to follow, or easy to install from without demonstrating a worthwhile result. There are no unresolved rubric definitions.
