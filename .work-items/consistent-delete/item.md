# Consistent Delete

Unify deletion across TableSage's deletable lists: retain reversible removal marks while users work within a list and its sub screens, then commit deletion automatically when users navigate out of that list's context.

The accepted proposal, qualitative success criteria, existing behavior inventory, documentation requirements, and design discussion are recorded in [idea.md](idea.md). The user explicitly chose qualitative criteria without numerical scores or anchors.

Completed on 2026-09-30 at the user's explicit request. The user confirmed that Consistent Delete has been implemented. Closure is based on that confirmation; no independent implementation verification or quality evaluation was performed during this tracking update.
