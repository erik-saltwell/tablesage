# Triage labels

Use these canonical states in local issue Markdown:

| State | Meaning |
| --- | --- |
| `needs-triage` | The issue has not yet been assessed or routed. |
| `needs-info` | More information is required before work can proceed. |
| `ready-for-agent` | The issue is sufficiently specified for an agent to implement. |
| `ready-for-human` | The issue requires human judgment, access, or action. |
| `wontfix` | The issue has been deliberately declined or closed without implementation. |

Use one state at a time. Record it plainly in the issue rather than inventing repository-specific aliases.
