# Campaigns and Glossaries

A **Campaign** is the long-lived home for related Sessions and a campaign-specific Glossary. It has a name and can include a description and game system.

## Sessions in a Campaign

The Campaign gives its Sessions a sequence and a shared history. Each Session records one occasion of play; its artifacts preserve what happened and provide material that later Sessions can build on.

Session numbers follow creation order. Dates determine which earlier Session supplies the recap at the start of a later session summary; see [How the Prior Recap Is Chosen](sessions.md#how-the-prior-recap-is-chosen). For games without recordings and upcoming Sessions, see [Sessions without Recordings](../guides/start-a-campaign.md#sessions-without-recordings).

## Glossary

A **Glossary** is the Campaign-specific reference for names and terminology: people, places, factions, items, setting concepts, and unusual spellings. Each entry records a term and an optional description.

The Glossary belongs to one Campaign because the same word can mean something different in another game. It gives the group one place to establish the names that should remain consistent as the Campaign grows. The Glossary informs the spelling suggestions made while processing a Session and helps generated artifacts use the Campaign's established terminology consistently.
