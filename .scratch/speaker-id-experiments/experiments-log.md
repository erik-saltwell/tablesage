# Speaker identification — experiments log

Tracks attempts to improve speaker identification quality, scored against the
[speaker identification benchmark harness](../../.documentation/speaker_identification_benchmark.md).

Status is one of:

- **Unstarted** — idea captured, no design doc yet.
- **Designed** — has a dedicated design doc, not yet run.
- **Tried** — run against the benchmark harness; result recorded below.

Result type (populated once Status is Tried):

- **Success** — improved benchmark scores enough to adopt.
- **Failure** — did not improve scores, or regressed something; not adopted.

| 8 | Diarization-cluster propagation: ElevenLabs already clusters the whole session into consistent speaker IDs, which `identify_speakers` overwrites per-utterance and discards — both the online-research and code-review passes independently ranked this the #1 opportunity. Pool each diarized cluster's embeddings (duration-weighted, from its confident ≥2s utterances, which are 97% correct/0% error), assign clusters to players (greedy or Hungarian one-to-one), propagate labels to the cluster's short/unassigned utterances, with a per-utterance veto where an utterance's own evidence strongly contradicts its cluster. Directly attacks the real bottleneck: among the 80 currently-unassigned utterances, best-match==actual is only 42.5% (21% under 0.5s) — the *embedding* is unreliable for short clips, so no threshold tuning can fix them; inheriting cluster identity sidesteps their embeddings entirely (even the <0.15s too-short class gets labeled). Literature: cluster-then-identify is the standard speaker-attributed-ASR architecture; Microsoft reports up to 68% relative attribution-error reduction from graph-based propagation vs. independent per-utterance decisions (arXiv 2102.03634). **Blocking prerequisite:** frozen `ground_truth.json` no longer carries the raw diarized cluster IDs — fixtures need a one-time re-freeze preserving them alongside corrected names; also measure ElevenLabs cluster purity on the 2 labeled sessions first, since that number bounds the whole family | Unstarted | — | — | — |
| 9 | Short-utterance embedding widening: for utterances under ~1s, merge adjacent audio from the *same diarized cluster* (nearest same-cluster spans, up to ~2–3s) before embedding, instead of embedding the bare clip. Root cause targeted: a 0.24s utterance yields ~22 fbank frames — for sub-0.5s unassigned utterances, best-match==actual is just 21%, so their embeddings barely encode speaker identity at all. Cluster-guided widening (not raw time-padding, which would ingest other speakers in fast back-and-forth table talk) gives the embedder enough audio to work with. Companion clean-ups: revalidate `MIN_UTTERANCE_DURATION_SECONDS=0.15` (documented as an *eres2netv2* NaN cliff, never revalidated for WeSpeaker) and add a duration-bucket breakdown to the benchmark's `print_report` so every future experiment sees this axis. | 11 | Adaptive score normalization (AS-Norm): normalize each utterance-vs-player cosine score by top-N imposter-cohort statistics (cohort = a few hundred held-out speakers, e.g. VoxCeleb dev, embedded through WeSpeaker once and shipped as a resource file).
