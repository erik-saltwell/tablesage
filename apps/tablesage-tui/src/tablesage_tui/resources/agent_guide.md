# TableSage Workspace Guide for Coding Agents

This folder is a TableSage workspace. TableSage $version wrote this pointer to its public documentation.

Before answering questions about TableSage, run these read-only commands from this folder:

1. `tablesage output-help-topic guides/advanced-help` — follow its diagnostic boundaries and command instructions.
2. `tablesage output-help-topic reference/troubleshooting-faq` — for a problem, start with this public troubleshooting page.
3. `tablesage report-help-topics` — find other public topics relevant to the question.

The topics are the same documentation users see on GitHub, supplied by the installed application. Use them as the source of application behavior; do not inspect application source code. Diagnostics do not require reading Session narrative content or changing workspace files. If this pointer is outdated, the commands warn and continue; use the current public topics rather than old instructions. If a command fails, report its error and uncertainty rather than guessing.
